# Xsrazy Landing Page

**Live: https://xsrazy.web.id**

Personal landing page of Xsrazy: a single page that introduces who I am, what I do, and where to find me, with links to my projects and social profiles.

Built as a fast static site and deployed on Vercel. This repo is connected to the Vercel project, so every push to `main` updates the live page automatically.
