# Xsrazy Landing Page

**Live: https://xsrazy.web.id**

This is the personal portfolio landing page of Rahmatul Usra. The single-page site is his public face and entry point to his projects.

## Site Contents

- **Hero:** a "Welcome to my portfolio" greeting, the name Rahmatul Usra, and his personal tagline.
- A single lightweight page that goes straight to the point, with no complex sub-pages.

## Frontend

- Next.js (App Router) with React and TypeScript.
- Tailwind CSS styling.

## Backend

- No custom backend. There are no API routes, databases, or user accounts in this repo.
- All content is static and rendered by Next.js.

## Project Structure

```
app/         page.tsx and layout.tsx
components/  Page UI components
public/      Static assets
```
