# Xsrazy Landing Page

**Live: https://xsrazy.web.id**

Halaman portofolio pribadi Rahmatul Usra. Situs satu halaman ini menjadi wajah publik dan titik masuk ke project-project miliknya.

## Isi Web

- **Hero:** sapaan "Welcome to my portfolio", nama Rahmatul Usra, dan tagline pribadinya.
- Halaman tunggal yang ringan dan langsung ke inti, tanpa halaman turunan yang kompleks.

## Frontend

- Next.js (App Router) dengan React dan TypeScript.
- Styling memakai Tailwind CSS.

## Backend

- Tidak ada backend khusus. Tidak ada API route, database, atau akun pengguna di repo ini.
- Semua konten bersifat statis dan dirender oleh Next.js.

## Struktur Project

```
app/         page.tsx dan layout.tsx
components/  Komponen UI halaman
public/      Aset statis
```
